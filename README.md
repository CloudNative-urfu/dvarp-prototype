# DARP prototype runs

Код, отчёты и независимая критика сохранённых ревизий прототипа DARP.

- `revisions/darp-revision-2/prototype/` — текстовые исходники, конфигурации и отчёты второй ревизии.
- `revisions/darp-revision-2/review/` — независимая критика и адресные пробы.
- `source-manifest.json` внутри ревизии — хеши полного исходного снимка.
- `export-manifest.json` — хеши экспортированных файлов и перечень оставленного вне Git.

Полные снимки, сырые прогоны и журналы сохранены локально в
`~/.local/share/research-campaigns/`; экспорт в Git их не заменяет и не удаляет.
Крупные артефакты, веса моделей и окружения в Git не входят.

Результаты тестов относятся к конкретной ревизии. Завершение кампании не означает
устранение всех замечаний или подтверждение эффективности защит: см. её критику.
