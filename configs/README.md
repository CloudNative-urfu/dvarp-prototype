# configs/

Предзарегистрированные (замороженные) конфигурации прогонов — результат компонента `configs`.

- `<name>.json` — конфигурация: гвардрейлы и точки установки, политика реакции с порогами,
  правила процесса (`g_proc`), защищаемая сторона, `seed_label`, `control_of`; вычисленные поля
  (`resolved` — параметры плагинов с умолчаниями и версии кода защиты, `operational_definition`,
  `fingerprint`), отпечаток границы исполнителя `executor_boundary` (FR-1.14: один для всех).
- `configs.lock.json` — sha256 каждого файла, отпечаток набора, хеш кода защиты, раздел
  `post_hoc` (конфигурации, добавленные после блокировки; в основной вывод не входят).
- `history/` — прежние lock при перезаморозке до итогового теста (`freeze --replace`).

Команды: `python3 -m darp_range.configs verify --dir configs` (дрейф → код 1),
`python3 -m darp_range.configs list|show NAME`. Цены break-even и параметры очереди задаются
допущениями decomposition и компонентами `metrics`/`manual_queue`, не здесь: они одинаковы для
всех конфигураций.
